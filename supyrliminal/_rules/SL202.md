# SL202 — Broad `# noqa` (3+ SL/PYD codes)

## Cause

A single `# noqa` comment lists 3 or more SL/PYD codes, suppressing
several findings at once. This pattern defeats per-construct review
and bypasses the registry.

## Fix

Split into one `# noqa: <single-code>` per line, each backed by a
registry entry. Use the suppression scanner's `SL203` to verify each
entry.

```python
# Before — SL202
result = adapter.validate(x)  # noqa: SL001, SL002, SL003

# After — one registry-backed suppression
# noqa: SL001  (see pyproject.toml [tool.supyrliminal.suppressions])
```

## Suppression

SL202 cannot be authorized by the registry.
