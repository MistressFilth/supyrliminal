# SL003 — Deprecated @root_validator

## Cause

The `@root_validator` decorator is deprecated in Pydantic V2
(`pydantic/migration.md:416-417`).

## Fix

Use `@model_validator(mode='before')` or `@model_validator(mode='after')`.

```python
# Before — SL003
class Card(BaseModel):
    @root_validator
    def check(cls, values):
        return values


# After — no violation
class Card(BaseModel):
    @model_validator(mode="after")
    def check(self):
        return self
```

## Suppression

Suppress with `# noqa: SL003` on the decorator line.
