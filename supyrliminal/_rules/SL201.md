# SL201 — Blanket `# noqa` with no codes

## Cause

A `# noqa` comment is written without listing any specific code, suppressing
every flake8 finding on that line (not just SL/PYD).

## Fix

Replace `# noqa` with `# noqa: SLxxx` listing the specific codes being
suppressed, or remove the line entirely.

```python
# Before — SL201
x = something()  # noqa

# After — no violation
x = something()  # noqa: SL001  (per-call adapter is intentional)
```

## Suppression

SL201 cannot be authorized by the registry. Use the specific-code form
(`# noqa: SLxxx`) for any suppression you need to keep.
